# MirageTNT-v0.1.1
Динамиты 5 тиров для Paper 1.21.4+ — приваты ломаются по прочности, а не сразу, плачущий обсидиан даёт двойную защиту, у каждого тира своя уникальная механика: штурмовой заряд, бронебойный, ледяной, расхититель спавнеров и титан. Плюс динамитная пушка, тревога владельцам, трещины на приват-блоке, обезвреживание ножницами, топ рейдеров и лог рейдов.
